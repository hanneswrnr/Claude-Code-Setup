Hannes will fuer GitHub kein Geld ausgeben (Ansage vom 21.09.2026). Also keine Vorschlaege, die GitHub Pro, ein hoeheres Ausgabenlimit oder zusaetzliche Actions-Minuten voraussetzen.

**Why:** Ausdrueckliche Vorgabe, nachdem ich ihm geraten hatte, ein Abrechnungsproblem in den GitHub-Einstellungen zu loesen.

**How to apply:** Server-Pruefungen, die Actions-Minuten kosten, durch lokale Git-Hooks ersetzen oder ergaenzen. Bei SchadenMelden24 liegt dafuer bereits alles in .githooks und muss nur einmalig pro Klon aktiviert werden. Branch Protection ist dort ohnehin nicht verfuegbar, weil das Repo privat und ohne Pro ist.
