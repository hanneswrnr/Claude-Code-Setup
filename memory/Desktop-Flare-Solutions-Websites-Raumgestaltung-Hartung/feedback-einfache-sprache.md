When reporting what is missing or what someone has to do, use plain, simple German: short sentences, grouped lists ("was ich mache" / "was ihr tun müsst" / "was im Rechtstext fehlt"), and explain any technical or legal term in one sentence (e.g. SPF, AVV, env vars) instead of assuming it is known.

**Why:** On 2026-09-10 the user asked "Sag mir genauer was jetzt noch fehlt und in einfacher Sprache!" after a jargon-heavy status answer.

**How to apply:** Default to this style for status updates and to-do lists in this project; keep the dense technical detail for code comments and docs.
