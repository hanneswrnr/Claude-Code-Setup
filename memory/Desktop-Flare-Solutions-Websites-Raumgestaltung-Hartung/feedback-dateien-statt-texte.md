When something has to go to a third party (e.g. DNS zone file for the IT provider Kai Hinzberg), Hannes wants the finished file itself — in the original format and under the original file name — ready to forward. No accompanying message text for him to copy (correction on 2026-09-11: "Du sollst mir keinen Text für Kai geben sondern du sollst die Excel richtig anpassen und ich schicke sie Ihm dann!").

**Why:** He does not want to write or relay explanations and wants to avoid back-and-forth with the IT provider.

**How to apply:** Make the file self-sufficient and robust (same format and name as the third party's original, no assumptions that need explaining). Put ready-to-send files into a clearly named folder such as `Downloads\Fuer-Kai\`. Anything that cannot be encoded in the file, verify ourselves afterwards (e.g. check DNS at the nameservers) instead of asking the third party.
